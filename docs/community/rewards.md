# Vote Party

Every **50 total server votes** triggers a **Vote Party**.

All online players receive:

## 🎲 Key Roller

The Key Roller gives **one random crate key**.

Possible rewards:

| Chance | Reward |
|:------:|:-------|
| **50%** | Common Crate Key |
| **30%** | Rare Crate Key |
| **15%** | Epic Crate Key |
| **5%** | Legendary Crate Key |

All crate keys can be opened at:

```text
/warp crates
```
