# Connect to the Server

## 1. Launch Minecraft

Open **Minecraft: Java Edition**.

---

## 2. Add a Server

Click **Multiplayer** → **Add Server**.

---

## 3. Enter the Details

**Server Name**

```text
ArteryX
```

**Server Address**

```text
play.arteryx.xyz
```

Click **Done**, select **ArteryX**, then click **Join Server**.
