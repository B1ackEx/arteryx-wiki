# Connect to the Server

## Java Edition

### 1. Launch Minecraft

Open **Minecraft: Java Edition** using a supported version.

For the best experience, we recommend:

```
26.1.2
```

### 2. Add a Server

Click:

**Multiplayer → Add Server**

### 3. Enter the Details

**Server Name**

```text
ArteryX
```

**Server Address**

```text
play.arteryx.xyz
```

Click **Done**, select **ArteryX**, then click **Join Server**.

---

## Bedrock Edition

ArteryX also supports **Minecraft: Bedrock Edition**.

### Server Address

```text
play.arteryx.xyz
```

### Port

```text
25565
```

Go to:

**Servers → Add Server**

Enter the address and port, then connect.

!!! note

```
Bedrock players can play together with Java players on ArteryX.
```

# Your First Steps

Once you join ArteryX:

* 🧱 Start your OneBlock island.
* ⛏️ Break your OneBlock and progress through phases.
* 🏝️ Expand your island.
* 📈 Check your island level with `/ob level`.
* 🚀 Upgrade your island with `/ob upgrade`.
* 🌎 Explore unlocked phases with `/ob phases`.
* ⚙️ Configure your island with `/ob settings`.
* 💰 Start building your economy.
* 🗳️ Vote for rewards.
* 🎁 Explore crates and rewards.
* 🏪 Trade with other players.
* 💬 Join the ArteryX community.
