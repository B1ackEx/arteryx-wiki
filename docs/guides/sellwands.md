# Sell Wands

Sell Wands instantly sell everything inside a chest with a single click.

They're one of the biggest quality-of-life features on ArteryX.

---

## How to Use

1. Hold a Sell Wand.
2. Right-click a container.
3. Everything inside is sold instantly.

No need to manually sell items anymore.


---

## Tiers

There are **3 Sell Wand tiers**.

### 🪵 Stick Sell Wand

Perfect for beginners.

Uses:

- 5
- 25
- 50

---

### 🌬️ Breeze Sell Wand

Great for growing farms.

Uses:

- 75
- 150
- 250

---

### 🔥 Blaze Sell Wand

Built for large automatic farms.

Uses:

- 500
- 750
- 1000

Sell Wands use the exact same prices as:

```text

```

They simply save time by selling everything instantly.
